Network rules

per-tag egress allowlists — applied to running machines that share a tag
A rule-set is a list of domains a machine may reach. Tag a machine with a rule-set's tag and, while it runs, its egress is restricted to those domains (plus its own gateway) — everything else is blocked at the host. Untagged machines are unaffected. Rules take effect within seconds; existing connections may linger briefly.

Repos

GitHub checkouts cloned into machines that share a tag
An attachment is configuration, not a copy: a machine created with one of these tags clones the repository while it boots, into ~/<name> — or ~/src/<owner>/<name> once more than one is attached. Tagging a machine that already exists never clones: the entry appears as not cloned, and sparkbox repos sync inside the machine does the work when you ask for it. Detaching leaves existing checkouts where they are.
