# Sparky

A repository of experiments for the OpenClaw instance running on a DGX Spark. Its name is Sparky.

## Tools

| Tool | Description |
|------|-------------|
| [sluice](tools/sluice/) | DNS allowlist gateway + eBPF egress meter for sandbox VMs: restrict which domains a VM can reach and account bandwidth per domain. |
| [stateus](tools/stateus/) | Determine which U.S. states you spent time in each day of the year using Google Maps location history. |
